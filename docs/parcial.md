## 1) Realice el diseño lógico conforme las siguientes reglas de negocio:

La clínica "SANTA PAZ" necesita llevar un control informatizado de su gestión de pacientes y médicos.

De cada paciente se desea guardar un código, nombres, apellidos, dirección, ciudad, provincia, código postal, teléfono y fecha de nacimiento. De cada médico se desea guardar un legajo, nombres, apellidos, teléfono y especialidad.

Se desea llevar el control de cada uno de los ingresos que el paciente hace en el hospital. De cada ingreso se guarda el código de ingreso, el número de habitación y cama en la que el paciente realiza el ingreso y las fechas de ingreso y egreso. Cada ingreso tiene un médico asociado como responsable de este. Un paciente puede realizar varios ingresos en el hospital.
